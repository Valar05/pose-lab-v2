# Animation Apprentice Contract

This is the repo-native learning contract recovered from the Droobiedoo Animation Apprentice skill. Pose Lab V2 must not require the sibling checkout to use it.

## Loop

brief -> motion recipe -> key poses -> critique -> correction note -> reusable lesson -> improved draft

The purpose is not merely to make one animation pass. The purpose is to preserve why the next draft should be better.

## Motion recipe

Before generating transforms, identify the animation family, camera perspective, target rig, runtime target, prop involvement, intended feel, anticipation, initiation, action, impact/contact, follow-through, and recovery.

Each key pose should record timing, purpose, balance state, silhouette/readability, and body-mechanics intent.

## Correction note

Convert useful critique into a durable note with: target, user_words, visible_problem, intended_fix, scope, confidence.

Preserve visible-language critique when possible. Do not translate a screen-space complaint into an unverified rig-space theory and then treat the theory as truth.

## Animation lesson

Promote a correction into a reusable lesson only when it generalizes. A lesson should contain trigger/family, rule, evidence source, applicable characters/weapons, and status.

A later candidate should name the lesson it applied and where it changed the result.

## Pose Lab integration

Use the existing Pose Lab V2 evidence stack:

- clip ledgers and contact sheets for source timing;
- saved poses for literal authored keys;
- animation:compose for timed candidates;
- animation:compare for no-op detection;
- Blender render truth for local visual diagnostics;
- hosted browser evidence for acceptance;
- promote:animation only after accepted evidence.

For attacks, preserve the current hold/snap/hold/recover doctrine and the boring hand-to-weapon ownership chain. For imported Sprite Lab drafts, preserve source bytes, boxes, frame blobs, timing, and IndexedDB restoration.

## Anti-patterns

Do not jump from a prompt directly to opaque transform arrays, bury useful critique only in chat, overwrite corrected poses without provenance, treat imported clip names as behavioral truth, optimize pretty stills while motion readability fails, use metrics as visual acceptance, or make a sibling skill/hidden memory an operational dependency.

## Acceptance

This contract succeeds when a later draft is measurably improved by a durable lesson from earlier critique and the evidence chain shows which lesson changed what.
